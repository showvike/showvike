# Portfolio Blueprint

## Content Model

- Central portfolio data lives in `src/data/portfolio.ts`
- Home route is rendered from `src/app/page.tsx` and `src/components/landing-page.tsx`
- Section components live under `src/components/sections`
- Global shell components live under `src/components/layout`

## Homepage Sections

- Hero: name, title, summary, stats, and primary calls to action
- Skills: grouped by expertise, comfortable, familiar, and tools
- Experience: role history with responsibilities and key production projects
- Selected Projects: concise recruiter-friendly project cards
- Problem Solving: external competitive programming profiles
- Education & Achievements: degree, contest history, and community contribution
- Contact: working links for email, LinkedIn, GitHub, and resume

## Design Direction

- Preserve the existing dark visual identity
- Improve hierarchy, spacing, and mobile responsiveness
- Keep content concise, professional, and impact-focused
- Avoid placeholder content, fake metrics, and non-working calls to action
