# **App Name**: Showvike's Showcase

## Core Features:

- Profile Overview: Display professional summary, skills, and contact information.
- Experience Highlights: Showcase work experience with descriptions of roles and responsibilities at Doodle Inc. and Tiggzy IT.
- Project Portfolio: Present key projects with tech stacks, descriptions, and links to GitHub or live demos.
- Problem-Solving Showcase: Include links to HackerRank, Codeforces, and LeetCode profiles to show problem-solving skills.
- Achievements and Education: Display educational background, achievements, and contest participations.
- AI Resume Analysis: AI-powered tool which highlights skills in resume using natural language processing.
- Contact Form: Enable direct contact through a contact form that sends messages to your email.

## Style Guidelines:

- Primary color: Slate blue (#708090) for a professional and reliable feel. This color evokes a sense of trust and competence.
- Background color: Light gray (#E5E7EB), which is almost white, to ensure a clean and modern backdrop that keeps focus on the content.
- Accent color: Steel blue (#4682B4), which will provide contrast on buttons and interactive elements, highlighting them for user interaction.
- Body text: 'Inter', sans-serif
- Headline Font: 'Space Grotesk', sans-serif
- Use FontAwesome icons for skills, tools, and external links to enhance visual appeal and user navigation.
- Design a clean, responsive layout with clear sections for easy navigation and readability.
