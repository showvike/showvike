# Nextn - Showvike Mondal Ovi Portfolio

A personal portfolio website for Showvike Mondal Ovi, a software engineer based in Mirpur, Dhaka, Bangladesh.

## Stack

- **Framework**: Next.js 16.2.2 (React 18)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Radix UI + clsx + tailwind-merge
- **Forms**: React Hook Form + Zod + @hookform/resolvers
- **Animation**: Framer Motion
- **Data**: React Query + Firebase
- **AI**: GenKit + Google AI
- **Charts**: Recharts
- **Date**: date-fns + react-day-picker

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Dev server on port 9002 |
| `npm run build` | Production build |
| `npm run lint` | ESLint check |
| `npm run typecheck` | TypeScript check |

## Features

- Full-stack web portfolio
- Shopify themes and apps expertise showcase
- Experience timeline with work history
- Contact and resume download
- AI-powered features (via GenKit)
